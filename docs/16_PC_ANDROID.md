# PC y Android

| Aspecto | Windows PC | Android |
|---|---|---|
| Entrada cámara | Arrastre con el botón derecho o central, WASD para desplazarse, rueda para el zoom, Q/E para rotar en pasos de 45° | Un dedo para desplazar, pellizco para el zoom, dos dedos girando para rotar |
| Selección | Clic izquierdo; hover con resaltado suave | Toque (`PointerGesture`: umbral de 2,5 mm); pulsación larga para información |
| Apuntado (P4) | Ratón con precisión; mantener pulsado para la potencia | Arrastrar la retícula y mantener el botón de disparo para la potencia |
| UI | Hover, tooltips, atajos | Botones ≥ 48 dp, zonas seguras, respuesta háptica |
| Calidad | Alta: sombras 4 cascadas, SSAO, MSAA 4× | Media: 2 cascadas, sin SSAO, MSAA 2×, render scale 0,85 |
| Objetivo | 60 FPS en GPU de gama media (GTX 1060) | 30 FPS estables en gama media (Snapdragon 7xx) con opción de 60 |
| Backend gráfico | DX11 | Vulkan con alternativa GLES3 |
| Arquitectura | x64 | ARM64, IL2CPP, API mínima 26 |

Las reglas de juego son idénticas. Las ligas están separadas por plataforma (`11`).
