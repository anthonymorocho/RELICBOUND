# Temporadas y cosméticos (P12–P13)

- Duración de una temporada: 8 semanas. Al terminar, los puntos de liga se reajustan parcialmente (Leyenda → Diamante, etc.).
- Recompensas competitivas **solo cosméticas**: estandartes, escudos, bordes de perfil, skins de castillo y de máquinas, efectos de proyectil, decoraciones, títulos y celebraciones.
- Pase de temporada con ruta gratuita y premium, también solo cosmético.
- Una skin no puede cambiar las siluetas ni el tamaño de colisión, ni ocultar el estado de daño: la legibilidad competitiva es igual para todos.
- Las municiones «de temporada» solo pueden cambiar el efecto visual de una munición existente, nunca sus estadísticas.
